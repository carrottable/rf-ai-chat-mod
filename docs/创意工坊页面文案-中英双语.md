## 1. 标题 / Title

**RF AI 对话 · AI 实时生成士兵对话（中英双语）/ RF AI Chat - AI-generated soldier chatter**

## 2. 简短简介 / Short Description

**中文：**
> 让战场上的 AI 士兵用真实 LLM 实时开麦：按击杀/阵亡/据点/指令等事件触发对话，按 K/D 分四档人设，支持 @ 点名接话、战报播报与调试窗口。API Key 由玩家自行填写。

**English:**
> AI soldiers actually talk, generated live by a real LLM: event-driven chatter (kills, deaths, captures, orders), four persona tiers based on K/D, @-mention replies, battle reports and an in-game debug console. Bring your own API key.

## 3. 详细说明 / Detailed Description

### ✨ 功能 / Features

**中文：**
- **事件驱动对话**：击杀、阵亡、友伤、多杀、据点、指令、载具、玩家发言等事件自动触发
- **四档人设**：按 KD 名次分位数分配 新兵/老兵/精锐/王牌（比例、首次分配时间、重分间隔均可调）
- **@ 点名链**：AI 之间会互相 @ 接话，被点名必回；说话有冷却与频率限制
- **玩家相关插队**：击杀玩家/被玩家击杀/被玩家点名 等事件优先插队，第一时间上屏
- **战报系统**：手动战报 + 自动战报（间隔可调），含双方 KD 前三/复活票/比分
- **AI 公告栏关注**：系统播报后每队至少 5 名 AI 回应，开局/胜负各播报一次
- **调试窗口**：查看每条台词的原因、对象、档位、耗时、原始响应，可导出/重发
- **提示词体系**：全局 / 阵营 / 对局 / 角色 四层提示词 + 常识库，全部可在设置里编辑
- **中英双语**：台词可切换中文/English；MOD 设置界面固定中英双语显示

**English:**
- **Event-driven dialogue**: kills, deaths, team-kills, multi-kills, captures, orders, vehicles, player chat
- **Four persona tiers** by KD percentile: Rookie / Veteran / Elite / Ace (ratio, first-assign time and reassign interval configurable)
- **@-mention chains**: soldiers @ each other and always reply when mentioned, with cooldowns and rate limits
- **Player-priority events**: kills/deaths/mentions involving the player jump the queue
- **Battle reports**: manual + automatic (interval configurable), with top-3 KD, tickets and scores
- **System broadcast reactions**: after each broadcast at least 5 AI per team respond; opening and result broadcasts
- **Debug console**: reason, target, persona tier, latency, raw response; export & resend
- **Prompt layers**: global / faction / match / character + knowledge base, all editable in settings
- **Bilingual**: dialogue language switchable (Chinese/English); the mod settings UI always shows bilingual labels

### 🔧 安装 / Installation

**中文：**
1. 安装 **BepInEx 5.4.23.5**（Ravenfield 版），确认游戏根目录下有 `BepInEx/plugins/`；
2. 将 `RF.AiChat.dll` 放入 `BepInEx/plugins/RF.AiChat/`；
3. 将模组包 `RFAiChatUI.rfc` 放入 `ravenfield_Data/mods/RFAiChatUI/`；
4. 启动游戏 → 模组设置 → 勾选本 MOD → 填入自己的 API Key（OpenAI 兼容接口，默认 DeepSeek）→ 进入对局。

**English:**
1. Install **BepInEx 5.4.23.5** for Ravenfield;
2. Put `RF.AiChat.dll` into `BepInEx/plugins/RF.AiChat/`;
3. Put `RFAiChatUI.rfc` into `ravenfield_Data/mods/RFAiChatUI/`;
4. Launch the game → Mutators → enable this mod → enter your own OpenAI-compatible API key (DeepSeek by default) → start a match.

### ⚙️ 设置说明 / Settings

**中文：**
设置页内容固定中英双语显示。常用项：
- 语言 / Language：台词语言（中文 / English）
- 输入键 / Input Key：游戏中调出聊天框的按键（默认 Y）
- 说话频率 / Speech Rate：少 / 正常 / 多
- 字体 / FONTS：聊天字号
- 自动战报间隔 / Auto report：下拉选择 60~1800 秒
- 鹰队/鸦队/玩家名色：点开下拉选择颜色（含 CUSTOM COLOR 炫彩）
- 允许死亡AI发言 / Dead AI speak：阵亡/未部署的 AI 是否还能说话
- 右侧按钮：提示词设置 / 人设分配 / 常识库（均为插件面板）

**English:**
The settings page is always bilingual. Common entries:
- Language: dialogue language (Chinese / English)
- Input Key: key to open the chat box (default Y)
- Speech Rate: Low / Normal / High
- FONTS: chat font size
- Auto report: dropdown 60–1800 seconds
- Eagle/Raven/Player name color: dropdown with colors (incl. CUSTOM COLOR rainbow)
- Dead AI speak: allow dead/undeployed AI to keep talking
- Right-side buttons: Prompt Settings / Persona Settings / Knowledge Base

### 🔑 API Key 说明 / API Key

**中文：** 本 MOD 不内置任何 Key。请使用你自己的 OpenAI 兼容接口 Key；Key 只保存在本地配置/缓存，不会写入模组包。
**English:** No API key is bundled. Use your own OpenAI-compatible key; it is stored locally only and never packed into the mod.

### ❓ FAQ

- **没有台词？** 检查 API Key、模型名与网络；调试窗口能看到失败原因。
- **AI 不说话 / 太少？** 调高"说话频率"，或检查是否被复活次数/存活状态限制。
- **英文台词？** 设置里把"语言"切到 English。
- **No lines?** Check API key/model/network; the debug window shows errors.
- **Too few lines?** Raise Speech Rate, or check alive/reinforcement limits.
- **English dialogue?** Switch Language to English in settings.
