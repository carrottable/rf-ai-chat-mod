# 开发与构建说明

## 环境
- Windows 10/11
- .NET Framework 4.x（`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`）
- Ravenfield（Steam 636480）+ BepInEx 5.4.23.5
- Python 3.10+，`pip install -r requirements.txt`（UnityPy、lupa）

## 编译插件
```bash
export RAVENFIELD_DIR="/c/Program Files (x86)/Steam/steamapps/common/Ravenfield"
bash 20-源码/plugin/build.sh
```
产物在 `30-构建产物/RF.AiChat.dll`，并自动部署到 `$RAVENFIELD_DIR/BepInEx/plugins/RF.AiChat/`。

## 模组包（.rfc）
`.rfc` 内含 Lua 脚本（TextAsset）与 Unity 预制体。仓库不包含载体包（版权原因），
需要自备一个可用的 Mutator `.rfc`，用 `20-源码/tools/make_test_mod.py` 打包：

```bash
python 20-源码/tools/make_test_mod.py --donor 你的载体.rfc --lua 20-源码/lua/RFAiChat.lua \
  --name "RF AI 对话" --folder RFAiChatUI --behaviour RFAiChat --outdir 30-构建产物
```

## 只改 Lua 的热更新
```bash
export RFAICHAT_RFC="$RAVENFIELD_DIR/ravenfield_Data/mods/RFAiChatUI/RFAiChatUI.rfc"
python 20-源码/tools/hot_update_lua.py
```

## 回归检查
```bash
bash 20-源码/tools/run_checks.sh
```
包含：密钥泄露扫描、Lua 语法 + 假环境冒烟测试、C# 编译、（可选）模组打包。
设置环境变量 `RFAICHAT_DONOR_RFC` 可启用打包步骤。

## 架构
- `AiChatPlugin.cs`：BepInEx 入口、配置项、Update 调度
- `ChatEngine.cs`：事件 → 提示词 → API → 队列 → 显示；人设、战报、系统播报
- `OverlayChat.cs`：Plan B 自建聊天显示层（UGUI Text，富文本着色）
- `AiChatBridgeApi.cs`：暴露给 Lua 的桥（事件、Poll、输入焦点）
- `RFAiChat.lua`：游戏侧脚本（事件采集、人设分配、配置/设置页、官方 UI 接入）
