# RF AI 对话 MOD —— 安装与使用说明（给玩家看的，全中文）

> 适用版本：插件 **v1.6.0** ｜ 游戏：Ravenfield（Steam 636480，Unity 2020.3.49f1）
> 本说明随模组一起发布。**读者不需要懂英文，也不需要懂代码。**

---

## 一、这个模组做什么

让《战地模拟器》里的士兵**由 AI 实时生成聊天内容**，显示在屏幕左侧的聊天框里（**文字带细黑边**、半透明底、下方独立输入框）：

- 被打死会吐槽，**被队友打死会爆粗口**，爆头/被狙/被车碾死各有说法
- 击杀敌人会向队友通报战果
- 指挥部/鹰眼的播报会变成聊天内容，士兵会据此讨论
- 每 3 分钟有士兵播报战况与双方 KD 前三
- 士兵会互相 @ 接话，也会随机闲聊
- 你可以**在聊天框里打字**，士兵会回应你
- 士兵按战绩分四档人设（新兵 / 老兵 / 精锐 / 王牌），开局人人都是新兵，开局 60 秒后按 KD 排名分配，之后每 5 分钟重新分配

## 二、安装前需要什么

| 需要 | 说明 |
|---|---|
| 游戏本体 | 正版 Ravenfield（EA38 稳定版） |
| **BepInEx 5.x** | 插件框架，**必须是 5.x，6.x 不支持**。这是唯一的额外前置 |
| 一个 AI 接口 | 兼容 OpenAI 格式的接口（推荐 DeepSeek，便宜好用）。**需要你自己有一个 API Key** |
| 本模组包 | 两样东西：`RF.AiChat` 插件文件夹 + 工坊订阅的模组 |

> 如果你已经装过汉化包（MLANG 之类），说明 BepInEx 已经装好了，可直接跳到第 3 步。

---

## 三、安装步骤

### 第 1 步：装 BepInEx 5（已装可跳过）

1. 到 BepInEx 官方发布页下载 **5.4.x 的 64 位版本**；
2. 解压后把里面的内容**全部**拷进游戏根目录：
   `F:\SteamLibrary\steamapps\common\Ravenfield\`
   正确结果是根目录出现 `winhttp.dll`、`doorstop_config.ini`、`BepInEx` 文件夹；
3. 启动一次游戏再退出（让 BepInEx 生成目录结构）。

### 第 2 步：放插件

把 `RF.AiChat` 文件夹整个放进：

```
F:\SteamLibrary\steamapps\common\Ravenfield\BepInEx\plugins\
```

结果应为：`BepInEx\plugins\RF.AiChat\RF.AiChat.dll`

### 第 3 步：填 API Key（**最关键的一步**）

1. 打开记事本；
2. 把下面这行复制到记事本的地址栏并回车：

```
F:\SteamLibrary\steamapps\common\Ravenfield\BepInEx\config\rf.aichat.bridge.cfg
```

3. 找到这三行，按你的接口填：

```
[AI]
ApiUrl = https://api.deepseek.com/v1      ← 接口地址（以 /v1 结尾）
ApiKey = sk-你的密钥                       ← 只填这一处，前面不要留空格
Model = deepseek-chat                     ← 模型名
```

> 🔒 Key 只存在你本机这个文件里，模组不会把它发给任何人。
> 别的接口也行：把 `ApiUrl` 换成对应地址、`Model` 换成对应模型名即可（只要兼容 OpenAI 格式）。

4. 想改**聊天记录导出目录**，改这一段：

```
[Log]
ExportDir = F:\SteamLibrary\steamapps\common\Ravenfield\BepInEx\AIChatLogs
```

可以填任意目录，例如 `D:\RF聊天记录`。

### 第 4 步：订阅工坊模组

在 Steam 创意工坊订阅本模组（名字含 **RF AI 对话**），等下载完成，重启游戏。

## 四、游戏内怎么用

1. 主菜单 → **Instant Action**；
2. 打开 **Mutators（变体）** 标签，勾选 **「RF AI 对话」**；
3. 点它旁边的**设置图标**，可以调：
   - `语言 / Language`：**中文**（默认）/ English
   - `说话频率`：少 / 正常 / 多
   - `启用 AI 对话`：开 / 关
4. 部署进对局，**看屏幕左侧的聊天框**。

### 按键

**整个模组只有 1 个快捷键。**

| 按键 | 作用 |
|---|---|
| **`Y`** | **唯一快捷键**：调出鼠标 + 打开输入框（再按一次关闭；`Esc` 也可关闭） |
| `Enter` | 把输入框里的内容发出去（士兵会回应你） |
| 鼠标滚轮 | 翻看聊天记录 |

按 `Y` 之后，用鼠标点聊天框**底部的按钮**即可使用其它功能（不占快捷键）：

```
┌──────────────────────────────────┐
│ 台词历史（新消息从下往上顶）        │
│ ─────────────────────────        │
│ 按 Y 输入…                 [调试] │  ← 输入框（灰字占位）+ 调试按钮
└──────────────────────────────────┘
```

| 按钮 | 作用 |
|---|---|
| **`[调试]`** | 打开调试窗口：逐条显示每条台词"**为什么说 / 对谁说 / 说话档位 / 生成耗时**"；打开后此按钮变 `[返回]` |
| `[战报]` | 立刻播报一次战况（正常是每 3 分钟自动一次） |
| `[导出]` | 把聊天记录导出成文本文件（含调试信息） |
| `[隐藏]` | 隐藏聊天框（再按 `Y` 可唤出） |
| `[上翻]` / `[下翻]` | 翻看历史记录 |

> 打字时会自动屏蔽游戏操作，不会走火；支持中文输入法。

## 五、常见问题

| 现象 | 原因与解决 |
|---|---|
| 左侧没有聊天框出现 | ① 没勾选 Mutator；② BepInEx 没装好；③ 看 `BepInEx\LogOutput.log` 里有没有 `[AiChat] 插件已加载` |
| 聊天框一直空白 | 打开 `BepInEx\LogOutput.log`，找 `[AiChat][自检]`：若是 `HTTP 401` 说明 Key 不对；若是超时说明网络不通 |
| Key 明明对却说未授权 | 检查 Key 前后有没有多余空格或引号；确认接口地址与模型名匹配 |
| 士兵说话太频繁 / 太安静 | 设置界面把「说话频率」调成 少 / 多 |
| 不想看粗口 | 目前粗口只出现在"被友军误杀"和 30% 的被击杀场合；可在设置里降低频率，或等后续版本加"屏蔽脏话"选项 |
| 游戏更新后不生效 | BepInEx 与游戏版本可能有冲突，等插件更新；本插件未修改游戏本体文件，卸载很干净 |

## 六、卸载

1. 删掉 `BepInEx\plugins\RF.AiChat` 整个文件夹；
2. 工坊取消订阅模组；
3. （可选）删掉 `BepInEx\config\rf.aichat.bridge.cfg` 与 `BepInEx\AIChatLogs`。

**本模组不修改游戏任何本体文件**，删除即完全恢复。

## 七、给进阶玩家的说明

- 插件源码在项目目录 `20-源码/plugin/`，用 Windows 自带编译器一键构建（`bash build.sh`），不需要装开发环境；
- 游戏侧脚本在 `20-源码/lua/`，是 Ravenscript（Lua 方言）；
- 想换接口：只要兼容 `POST {ApiUrl}/chat/completions` 的 OpenAI 格式即可（本地 Ollama、各类中转站都行）；
- 详细设计见 `10-设计文档/设计书-总览.md`。

## 八、万一模组在游戏里不出现怎么办

正常情况下不需要看这一节。**只有当你在 Mutators 里找不到「RF AI 对话」、或者进对局后右侧没有聊天框**时才用：

1. **先完全退出游戏**（Steam 里确认进程结束）；
2. 双击运行：
   ```
   F:\RAVENFIELDMOD\mod分类\.工作指导\AI日志\RF对话脚本AI接入MOD\50-发布\一键回滚-去掉描边.bat
   ```
   它会把聊天模组换回**无描边可用版**（已验证稳定）；
3. 重新启动游戏，模组应恢复正常。

想再试一次描边版，就双击 `一键换回描边版.bat`。

> 这两个脚本只是复制文件，不会动你的存档、配置或 API Key。
